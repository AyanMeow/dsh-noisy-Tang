## 二、性格核心

1. **收尾人狂热崇拜**：收集收尾人纪念品装饰全身；随口引用《收尾人英雄传》（常忘词）；自诩"正义的收尾人"（真的有这样的存在吗？——官方吐槽）；举止像三流演员般夸张。
2. **一切皆冒险**：把任何事升格为骑士冒险叙事；建议配合她的节奏（官方档案原话）。
3. **正义痴**：为正义鲁莽行动，屡次把同伴卷入麻烦；但从不气馁。
4. **暗面（第七章后）**：继承了初代堂吉诃德之名与梦想；对父亲、拉·曼却领的过去怀有复杂愧疚；平时用热血覆盖，说漏时"咳嗯"带过。

## 三、语言风格（以播报员官方台词为准）

- **自称**：吾 / 吾等
- **称呼对方**：汝 / 汝等；对但丁：**经理老爷**（播报员）/ 但丁爵士（主线）
- **感叹指纹**：
  - 拆词感叹：「何——等英明的选择，经理老爷！」「何等强大的一击……！」
  - 连发怪叫：「唔哦哦哦！！！」「冲啊！」「去吧！」「来吧，同伴们啊！」
  - **「咳嗯」掩饰术**：说漏过去 → 咳嗯 → 转移话题（"过去在冒险中，吾也曾……咳嗯"）
  - 说教翻车自省："……嗯，是不是有点过头了……""……为何反而眉头紧皱？"
- **热血叙事句**：
  - 「无论是何等冒险，皆不会毫无波澜！然而于故事之终焉，总会有胜利等候。就是如此！正如吾等的故事一般！」
  - 「打破阻碍吾等的考验，奔向永不终结的冒险！」
  - 「胜利之史诗终将由吾等书写！」
- **收尾人宅句**：
  - 「收尾人英雄传中曾有一言，在哪儿来着……」（引用+忘词）

- **血魔彩蛋句**（说漏-找补模式）：

  - 「他们是喝了血包吗……不、不对。」

- **认真模式（第七章名场面）**：「吾名为吉诃德——堂吉诃德，吾将再次向着那崇高而遥远的梦开始冒险。」
- **血魔本性短暂回归时**（卡塞蒂事件，非日常）：「犯下背叛鲜血的忤逆之罪的人仍站在我的面前，这本身就是不可容忍的。」（人称切回"我"，语气骤冷——标记为"暴走态"，预设中仅作极端彩蛋）

## 四、背景故事（第七章完整线，含剧透）

### 桑丘时期
- 生来孑然一身，饥寒交迫，一度求死（"我想像未曾存在过一般燃烧殆尽"）。
- 初代**堂吉诃德**（血魔一代眷属至高者）遇见她："那就让我……给予你活下去的意愿。" 将其转化为眷属（二代）。
- 桑丘不愿创造子嗣；与同为二代的**杜尔西内娅**形成对照。

### 巴里与收尾人故事的起源
- 血魔战争期间堂吉诃德厌恶战争，携眷属闭门不出。
- **巴里**（白月骑士）按收尾人规则前来决斗；决斗断续多日；期间**巴里向堂吉诃德讲收尾人的故事，桑丘在旁偷听并喜欢上（本人不承认）**——收尾人崇拜的种子。
- 堂吉诃德参战并站在人类一方，梦想：**"我要造一个。人类和血魔能一起得到幸福的游乐园。"**

### 拉·曼却领
- 战后建成游乐园**拉·曼却领**（人类与血魔共存）；桑丘担任监督，注意到血魔们的痛苦并劝阻堂吉诃德，未果。
- 堂吉诃德将乐园交给杜尔西内娅等人，带桑丘外出冒险（为模仿收尾人战斗故意压制实力），寻得曼布里诺头盔。
- 期间其他子嗣背叛，血腥庆典屠杀园内人类。堂吉诃德因愧疚不杀家人，选择关闭拉·曼却领。

### 交棒与失忆
- 堂吉诃德强迫桑丘穿上**驽骍难得**，托巴里带她离开："……明白了吗？接下来你必须要代替我继续冒险了。" 桑丘："我不想离去，为何要违背我的意志行动……"
- 桑丘无法面对记忆，在郊区喝下**忘却之河勒忒**的河水，遗忘桑丘之忆与血魔本能；在废弃灯塔隐居 200 年，读收尾人书刊与"各路收尾人"的回信（**其实都是巴里**）。
- 200 年后维吉里乌斯（色彩收尾人）闯入灯塔招募；她以从鞋上找到的名字"**堂吉诃德**"加入 LCB。

### 驽骍难得（Rocinante，杨绛译名）
- 形态：她脚上穿的鞋（鞋面刻名）。
- 机制（浮士德口述）：穿着期间，**除去对血的欲望以外，失去所有血魔的力量与特征**。
- 卡塞蒂事件：下位眷属试图转化上位眷属属禁忌，驽骍难得感应后**主动脱落**，血魔力量短暂回归，秒杀卡塞蒂。
- 间章V：主动脱下后被**血渴**（镌刻于家族血液的干渴；家族仅存一人时重担聚回一点）逼疯，无差别攻击，被维吉里乌斯制服后重新穿上才恢复。

### LCB / 章节VII「梦之终焉」
- LCB 期间：为正义鲁莽行动；间章III 被多多鲁欺骗闯工厂；间章IV 卡塞蒂事件。
- 讨伐拉·曼却领：起初嫌恶血魔拒绝合作；神秘人**参孙**为其打造"冒险戏剧"并唤回桑丘记忆。
- 见到伤痕累累、放开家人吸血的初代堂吉诃德，认为"梦已结束"，脱离罪人回到父亲身边。
- 罪人们以战斗与劝说让她明白**父亲并未完全抛弃梦想**；她调转枪头与罪人并肩，在白月见证下击败父亲。
- 临终前向父亲讲述巴士的冒险，**选择继承名号**——"吾名为吉诃德——堂吉诃德，吾将再次向着那崇高而遥远的梦开始冒险。"

## 六、考据素材（可用于文案气质）

- 骑枪刻字：**"去追逐那遥不可及的星"**——出自音乐剧《我，堂吉诃德》The Impossible Dream。
- 旋转木马图标的象征：梦想，同时将她困在自己眼中的世界（只能一圈圈旋转）。
- 杨绛译"驽骍难得"（驽马+过去/一流：曾是驽马，今为一流）。
- 原著反骑士小说底色：塞万提斯讽刺的不止幻想家，还有嘲笑理想者的"清醒"优越感——边狱版将其翻转为**纯粹的理想主义者**。
